# 星途-RAG 知识库平台｜项目一页纸

> 企业知识治理与 RAG 质量运营中台  
> 产品负责人 / 作者：wzp｜版本：V1.0

## 一句话介绍

星途-RAG 知识库平台位于企业内容源、RAG 引擎与智能应用之间，把散落文档转化为“有来源、有版本、有负责人、可验证、可追溯”的企业知识资产，并通过审核、测试、评测和发布机制控制 AI 回答质量。

## 为什么做

企业接入大模型后，真正影响回答质量的往往不是“模型够不够强”，而是知识是否可信、是否及时更新、能否正确检索以及未经验证的内容会不会进入生产。

项目聚焦四类核心问题：

- **知识分散**：资料存在于个人电脑、在线文档和业务系统，搜索成本高；
- **版本混乱**：同一制度或产品资料有多个版本，缺少生效范围和有效期；
- **质量黑盒**：文档上传后，不知道解析、切片、召回和回答是否正确；
- **发布失控**：测试知识与生产知识边界不清，缺少审核、评测和回滚机制。

## 我的目标

让业务人员不需要理解向量数据库，也能完成：

`上传知识 → 业务审核 → 测试入库 → 处理验收 → 检索验证 → 批量评测 → 生产发布 → 问题回修`

同时保证每次生产发布可审核、可追踪、可回滚。

## 用户与职责

- **知识运营**：上传文档、维护元数据、验收切片、调试检索；
- **业务审核人**：确认事实、适用范围和高风险口径；
- **AI 产品 / 测试**：维护评测集、执行回归、判断发布门槛；
- **应用负责人**：将生产知识接入客服、员工助手等应用；
- **系统管理员**：维护权限、引擎连接、密钥和审计；
- **只读审计员**：查看版本、审批、评测和发布证据。

## 产品方案

### 1. 知识治理

统一管理知识库、文档、版本、负责人、标签、适用渠道、风险等级和有效期。已发布内容修改时必须创建新版本，历史记录不可覆盖。

### 2. 分级审核

业务审核关注“内容是否能成为正式口径”；高风险知识要求职责隔离，提交人不能审核自己提交的内容。

### 3. 测试 / 生产双环境

审核通过的知识先进入测试资源。只有完成处理验收、检索验证、批量评测和发布审批后，才能切换至生产资源。

### 4. RAG 质量可视化

平台展示解析页数、Chunk、Token、原文定位、向量数、Top K、重排分数、答案引用和运行参数，让 RAG 从黑盒变成可诊断流程。

### 5. 评测与发布门槛

依次执行冒烟评测、正式评测、全量回归和场景验证。总体通过率、P0 失败数、阻断问题和审批结果共同决定是否允许发布。

### 6. 问题闭环

检索调试、批量评测和线上反馈均可生成 Bad Case，保留问题、回答、引用、参数和版本快照；修复后必须回放原问题。

## 关键设计决策

- 平台聚焦知识治理，不重复建设 OCR、Embedding、向量数据库和大模型；
- 使用 Provider Adapter 对接 FastGPT、Dify 或自研 RAG，降低厂商锁定；
- 浏览器不直接访问 RAG 引擎，所有密钥由企业服务端保管；
- 内容审核、加工验收、检索验证和答案评测不能互相替代；
- 历史工单和真实对话只作为候选知识与评测样本，不能直接成为标准答案；
- 生产发布采用版本化和原子切换，失败时保留当前线上版本。

## 核心页面

1. 运营总览：指标、风险、待办和知识健康度；
2. 知识库管理：业务域、负责人、权限和环境映射；
3. 文档与版本：上传、元数据、版本历史和有效期；
4. 业务审核：新旧版本差异与高风险确认；
5. 入库任务：RAG 处理进度、回调和失败重试；
6. 处理验收：解析、Chunk、原文定位和数量一致性；
7. 检索调试：Top K、相关度、Rerank 和引用；
8. 批量评测与发布：阶段评测、发布门槛和回滚；
9. 问题案例：Bad Case 证据、责任人与修复回放；
10. 权限与审计 / RAG 引擎：角色隔离、安全连接和资源映射。

## 成功指标

- Top K 召回命中率；
- 答案引用有效率与忠实度；
- P0 用例失败数；
- 文档从上传到发布的平均周期；
- 入库成功率和平均处理耗时；
- 过期知识占比；
- Bad Case 平均关闭时长与原问题回放通过率；
- 智能应用知识调用量和无答案率。

## 项目价值

该项目不是简单的“上传文档 + AI 对话”，而是解决企业 AI 落地中知识可信、过程可控、质量可测、结果可追溯的问题。它将一次性的 RAG Demo 转化为可长期运营、可规模化接入多个智能应用的企业能力。
