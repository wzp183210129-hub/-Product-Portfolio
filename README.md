## 01 海睿星 · 智能客服 AI 助手

面向中型电商客服团队的 B 端 SaaS。以 **RAG + Copilot** 为主形态，按置信度分流 Case A/B/C（自动回复 / 审核后发送 / 转人工），把约 **60%** 重复问题交给 AI。

**解决什么问题**
- 日均咨询 2000+，客服在找答案、查系统、组织话术上耗时过长
- 高峰排队久、一次解决率低、新人培养周期长

**产品关键决策**
- 中置信度必须进审核队列，不得直接发给用户
- C 端不展示置信度，B 端展示便于审核
- V1 不做自动退款、改价等 Agent 动作，先跑通「有依据、可追溯、能转人工」

**关键结果**
- 首次等待：4.2 分钟 → 30 秒
- AI 直接解决占比 ≥ 60%
- 一次解决率：62% → 78%；满意度：3.8 → 4.3
- 客服人效：55 → 90 通/人/天；20 人团队承载约 35 人体量

📂 进入目录：[`智能客服-海睿星智能客服作品集`](./智能客服-海睿星智能客服作品集)

## 02 星途 · RAG 知识库运营平台

企业知识治理与 RAG 质量运营中台，位于内容源、RAG 引擎与智能应用之间。把散落文档变成 **有来源、有版本、有负责人、可验证、可追溯** 的知识资产。

**解决什么问题**
- 知识分散、版本混乱、质量黑盒、测试/生产边界不清

**核心能力**
- 知识治理 · 分级审核 · 测试/生产双环境
- RAG 质量可视化 · 评测发布门槛 · Bad Case 闭环
- Provider Adapter 对接 FastGPT / Dify / 自研 RAG，降低厂商锁定

**关键结果**
- 生产发布需通过评测与审批，失败可原子回滚
- 高风险知识职责隔离（提交人不可自审）
- 将一次性 RAG Demo 升级为可长期运营、可接入客服/员工助手的企业能力

📂 进入目录：[`RAG_Platform-知识库作品集`](./RAG_Platform-知识库作品集)

## 03 星途AI · 企业合同审核

面向甲方企业法务的 **「原则 → 规则库 → 合同审核」** 全链路 AI 辅助平台，覆盖 ERP / SaaS 采购合同审查。

**产品双模块**
1. **规则中心**：原则导入 → 识别 → 审核 → 入库 → 索引 → 检索 → 发布
2. **审核工作台**：上传合同 → 风险识别 → 三栏工作台 → 审核报告

**差异化**
- 按企业自有原则定制规则库，不是通用 ChatLaw
- 每条风险绑定规则 ID + 合同原文 + 相似度分数，结论可追溯
- 法务必审候选规则，测试与生产 dataset 分离

**关键结果**
- AI 约 30 分钟完成初筛，人工聚焦高风险条款
- 示例合同识别高/中风险共 38 条
- 完成 PRD、交互原型、选型说明与 Bad Case 复盘，支撑试点接入

📂 进入目录：[`AI_Contract_Review-AI合同审核作品集`](./AI_Contract_Review-AI合同审核作品集)

## 04 星途AI · 多仓就近发货路由

供应链智能产品线核心模块。订单支付后，AI 解析收件地址、过滤有货仓、计算最优距离，推荐最近发货仓——把「下单仓 = 发货仓」升级为「**最近有货仓 = 发货仓**」。

**解决什么问题**
- 仓库从 2 扩到 5 后，静态省份路由表失效，跨仓发货占比约 40%

**一期能力**
- 路由推荐 · 规则配置（覆盖区域 / 灰度→全量） · 健康巡检告警

**关键结果**
- 跨仓占比：40% → 15%（↓63%）
- 平均签收：3.5 天 → 2.3 天
- 单均物流：¥8.6 → ¥6.8（↓21%）
- 广州仓灰度：跨仓 35% → 8%，单均降本约 ¥2.3；人工改仓 < 5%；约 4 周上线
