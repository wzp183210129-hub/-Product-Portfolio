## 一、分析目的

不是做功能堆砌对比，而是回答三个问题：

1. 市场上已有玩家怎么解决智能客服？
2. 他们的 AI 方案强在哪、弱在哪？
3. **海睿星 V1 的差异化定位是什么？**

## 四、AI 方案深度对比

| 维度 | 行业常见做法 | 海睿星 V1 做法 | 差异说明 |
|------|--------------|----------------|----------|
| **自动化目标** | 追求高自动应答率（80%+） | 目标 60%，余下由人机协作 | 不拼数字，拼 **有效解决问题** |
| **AI 边界** | 部分产品允许 AI 触发工单/退款 | V1 禁止 AI 操作资金 | **合规优先** |
| **置信度展示** | 多数不展示或仅 B 端 | C 端用行为表达，B 端展示分数 | 用户体验优先 |
| **失败处理** | 转人工或「无法理解」 | 点踩 → 原因收集 → Bad Case 池 → 周复盘 | **闭环运营** |
| **知识来源** | 部分产品无强制引用 | 每条政策类回答必须带 doc 引用 | **可审计** |
| **Agent 能力** | 头部竞品已推 Agent | V1 明确不做，V2 只读 Agent | **稳健演进** |

## 五、竞品优劣势简析

### 智齿客服

| 优势 | 劣势 |
|------|------|
| 功能全面（呼叫+在线+工单+质检） | AI 能力偏「机器人」，RAG 引用不够透明 |
| 国内客户基础大 | 定制化重，中小企业上手成本高 |
| 与 CRM 集成深 | AI 边界文档不够清晰 |

### 网易七鱼

| 优势 | 劣势 |
|------|------|
| 与网易生态集成 | AI 能力跟进速度一般 |
| 质检和数据分析强 | 智能应答偏 FAQ 匹配 |
| 界面友好 | 复杂场景 Agent 能力不足 |

### Intercom Fin

| 优势 | 劣势 |
|------|------|
| GPT 原生，回答自然 | 国内部署和数据合规需额外方案 |
| Help Center RAG 体验好 | 按次计费，成本不可控 |
| 出海 SaaS 首选 | 与国内 ERP/OMS 集成弱 |

### 阿里小蜜

| 优势 | 劣势 |
|------|------|
| 平台级数据优势 | 绑定淘宝/天猫生态 |
| 自动率高 | 非平台商家无法用 |
| 大数据预测能力强 | 知识引用和审计能力弱 |

## 六、海睿星差异化定位

### 定位_statement

> **海睿星智能客服 ≠ 追求最高自动化的聊天机器人**
>
> **= 有依据、可追溯、人机权责清晰的企业级 AI 客服 Copilot**

### 三大差异化

| # | 差异点 | 对客户的价值 |
|---|--------|--------------|
| 1 | **强制来源引用 + 三层 AI 边界** | 答错能追责到 doc，合规可审计 |
| 2 | **Case A/B/C 置信度分流 + 中置信度必审** | 敏感场景不出事，客服有掌控感 |
| 3 | **Bad Case 周复盘闭环** | AI 不是上线即结束，越用越准 |
| 4 | **星途 AIGC 平台原生集成** | 与平台其他 AI 能力（内容生成、知识管理等）共享租户和数据 |

### 目标客户

| 客户类型 | 为什么选海睿星 |
|----------|----------------|
| 已用星途 AIGC 平台的企业 | 无需另接第三方，统一账号和知识库 |
| 中大型电商（日均 500+ 咨询） | 重复性问题多，RAG ROI 高 |
| 合规敏感行业（金融、医药电商） | 需要 AI 边界清晰、回答可追溯 |
| 客服团队 10-50 人 | 人机协作比纯自动化更现实 |

## 七、竞争策略（V1）

| 策略 | 具体做法 |
|------|----------|
| **不拼自动率** | 对外强调「有效 AI 解决率」而非「AI 应答率」 |
| **拼可审计** | 每条回答带引用，满足合规和内审需求 |
| **拼闭环** | Bad Case 复盘作为标准交付，不是增值服务 |
| **拼平台集成** | 星途 AIGC 平台一站式，降低接入成本 |
| **避 Agent 红海** | V1 不做自动退款，避免与头部正面竞争 |
