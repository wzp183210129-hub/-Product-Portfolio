# 星途AI · 企业合同审核 — 项目一页纸

> **作者**：wzp | **日期**：2026-09-02

---

## 一句话定位

**星途AI** 是面向甲方企业法务的 **「原则 → 规则库 → 合同审核」** 全链路 AI 辅助平台，让 ERP/SaaS 采购合同审查 **标准化、可追溯、可规模化**。

---

## 解决什么问题

| 痛点 | 星途AI 方案 |
|------|-------------|
| 法务审核耗时长 | AI 30 分钟完成初筛，人工聚焦高风险条款 |
| 审核标准靠个人经验 | 原则文档 → AI 结构化 → RAG 规则库 |
| AI 结论不可信 | 每条风险绑定规则 ID + 合同原文 + 相似度分数 |
| 规则难以维护 | 法务可视化采纳/修改/发布，版本化管理 |

## 产品双模块

```
┌─────────────────────┐     ┌─────────────────────┐
│  审核规则导入        │ ──► │  ERP合同AI审核       │

└─────────────────────┘     └─────────────────────┘
```

| 模块 | 核心能力 | 原型文件 |
|------|----------|----------|
| 规则中心 | 7 步：导入→识别→审核→入库→索引→检索→发布 | `审核规则导入原型Demo.html` |
| 审核工作台 | 上传合同→38 条风险→三栏工作台→审核报告 | `ERP合同AI审核原型Demo.html` |

## 技术方案（简版）

| 层级 | 选型 |
|------|------|
| 大模型 | 原则识别、规则拆解、审核意见生成 |
| RAG 引擎 | FastGPT（切片 + Embedding + 向量索引） |
| 检索策略 | 混合检索（HNSW 向量 + BM25 关键词） |
| Embedding | 企业中文语义模型 · 1024 维 |
| 召回阈值 | ≥ 0.75 才进入 AI 判断 |

## 差异化价值

1. **不是通用 ChatLaw**：按企业自有原则定制规则库  
2. **不是黑盒结论**：RAG 召回 + 规则 ID + 原文定位  
3. **不是全自动**：法务必审候选规则 + 风险决策  
4. **测试与生产分离**：先测试 dataset 验证再发布
