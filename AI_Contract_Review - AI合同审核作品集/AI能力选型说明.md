> **作者**：wzp  
> **日期**：2026-09-02  
> **适用范围**：企业合同审核（ERP SaaS 私有云采购场景）

---

## 1. 选型总览

| 能力环节 | 选型方案 | 备选方案 | 决策 |
|----------|----------|----------|------|
| 原则识别 & 规则拆解 | 大语言模型（GPT-4 级 / 国产同等） | 规则引擎 + NLP | ✅ LLM |
| 知识库存储 & RAG | **FastGPT** | Dify、自研向量服务 | ✅ FastGPT |
| 文本向量化 | 企业中文语义模型 · 1024 维 | OpenAI text-embedding-3 | ✅ 私有化 Embedding |
| 向量检索 | HNSW + BM25 混合检索 | 纯向量 / ES | ✅ 混合检索 |
| 合同结构化解析 | python-docx + PDF 解析 + LLM | 纯 OCR | ✅ 结构化优先 |
| 审核意见生成 | LLM + RAG 证据约束 | 纯 LLM | ✅ RAG+LLM |

---

## 2. 各环节详细说明

### 2.1 大语言模型（原则识别 / 规则拆解 / 审核判断）

**选型理由**：
- 审核原则文档为自然语言，需语义理解而非关键词匹配
- 需将抽象原则拆解为「触发条件 + 建议口径」结构化规则
- 需结合召回证据生成可解释的法务意见

**关键约束**：
- 私有化部署或企业专属 API 通道，合同数据不出域
- 输出 JSON Schema 约束，便于下游系统解析
- Temperature 设低（0.1~0.3），减少幻觉

**不选纯规则引擎的原因**：ERP 合同表述千变万化，硬编码规则维护成本极高，且无法处理语义等价表达。

---

### 2.2 FastGPT（RAG 引擎）

**选型理由**：
| 能力 | FastGPT 支持 |
|------|-------------|
| 知识库 API 推送 | ✅ 企业平台创建入库任务，异步回调 |
| 语义切片 | ✅ 按字段拆分触发条件与建议口径 |
| Embedding + 向量库 | ✅ 1024 维向量，HNSW 索引 |
| 混合检索 | ✅ 向量 + BM25 |
| 私有化部署 | ✅ 可内网部署 |

**与 Dify 对比**：

| 维度 | FastGPT | Dify |
|------|---------|------|
| 知识库 API 成熟度 | 高，支持外部任务 ID 回调 | 中，Workflow 为主 |
| 切片可控性 | 高 | 中 |
| 企业内网部署 | 成熟案例多 | 支持 |
| 定制开发成本 | 低 | 中 |

**决策**：FastGPT 的「外部推送 + 异步回调」模式与企业规则中心架构匹配度最高。

---

### 2.3 Embedding 模型

**选型**：企业中文语义模型 · 1024 维

**理由**：
- 合同与规则均为中文法律商务语体
- 1024 维在准确率与存储成本间平衡
- 支持私有化部署，满足数据合规

**不选 OpenAI Embedding 的原因**：合同数据敏感，不宜出境；且中文法律语体在通用英文模型上表现欠佳。

---

### 2.4 检索策略

**选型**：混合检索（向量相似度 + BM25 关键词）

```
合同条款 → Embedding → 向量 Top-K
                    ↘
合同条款 → 分词 → BM25 Top-K  →  融合排序 → 最终 Top-3
```

**参数**：
- Top-K：3（默认）/ 5（复杂条款）
- 召回阈值：≥ 0.75 进入 AI 判断
- 高风险主题（价格/数据/验收）：阈值降至 0.65 + 二次 LLM 确认

**不选纯向量检索的原因**：法律条款存在大量固定术语（「书面确认」「验收单」），BM25 可显著提升精确匹配。

---

### 2.5 合同文档解析

**选型**：结构化解析（DOCX/PDF）+ LLM 补全

| 格式 | 方案 |
|------|------|
| DOCX | 段落/表格/样式层级解析 |
| PDF | 文本层提取 + 版面分析 |
| 扫描件 | OCR（V2 规划，V1 不支持） |

**输出**：条款树（章节 → 条 → 款）+ 页码映射，供原文定位。

## 5. 风险与兜底

| 风险 | 兜底策略 |
|------|----------|
| LLM 幻觉 | Citation 约束 + 法务必审 |
| RAG 漏召回 | 阈值降级 + 人工复核队列 |
| FastGPT 不可用 | 规则缓存本地 + 降级为关键词匹配 |
| Embedding 模型漂移 | 版本锁定 + 发布前黄金集回归 |
