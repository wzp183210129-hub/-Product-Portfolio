## 1. 背景与目标

### 1.1 业务背景

企业采购 ERP SaaS 私有云部署类合同时，法务需从甲方立场审查付款、验收、数据安全、SLA、责任限制、退出机制等数十类风险。传统人工审核耗时长、标准难统一、新人上手慢。

### 1.2 产品目标

| 目标 | 指标 |
|------|------|
| 提升审核效率 | 单份合同初筛时间从 4h 降至 30min 内 |
| 统一审核标准 | 基于企业法务原则生成可执行规则库 |
| 结论可追溯 | 每条风险必须关联规则 ID 与合同原文 |
| 人机协同 | AI 辅助 + 法务最终决策，禁止全自动签署建议 |

### 1.3 非目标（V1.0 不做）

- 替代律师出具法律意见书
- 跨法域多语言合同审核
- 自动发起电子签章流程

## 2. 用户与场景

| 角色 | 核心诉求 |
|------|----------|
| 企业法务管理员 | 维护审核原则、发布规则库、抽检 AI 结论 |
| 采购/业务法务 | 上传乙方合同、处理风险清单、导出审核报告 |
| IT/平台管理员 | 对接 FastGPT、配置向量库与回调 |

**典型场景**：甲方采购 392 万元 ERP SaaS 私有云部署服务，收到乙方合同 DOCX，需在 2 个工作日内完成风险审查并输出谈判条款。

## 4. 功能需求

### 4.1 规则准备（审核规则导入）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| F1 原则文件上传 | 支持 DOCX/PDF，单文件 ≤20MB | P0 |
| F2 AI 原则识别 | 提取审核主题、义务/禁止事项、数值阈值 | P0 |
| F3 候选规则生成 | 17 项原则 → 26 条可执行规则（含触发条件、建议口径） | P0 |
| F4 法务审核工作台 | 单条/批量：采纳、修改、不采纳 | P0 |
| F5 置信度展示 | 低置信度原则需人工确认 | P1 |

**业务规则**：
- 未经法务采纳的规则不得进入入库任务
- AI 只负责识别与结构化，不决定正式规则效力

### 4.2 RAG 处理与验证

| 功能 | 描述 | 优先级 |
|------|------|--------|
| F6 测试入库任务 | 创建任务、推送 FastGPT API、登记回调 | P0 |
| F7 处理与索引 | 展示切片、Embedding、向量库、索引一致性 | P0 |
| F8 检索调试 | 输入合同条款，验证 Top-K 召回与相似度 | P0 |
| F9 规则库发布 | 测试通过后发布 V1.0，绑定审核场景 | P0 |

**业务规则**：
- 测试环境与生产环境 dataset 分离
- 切片数 = 向量数 = 索引数，不一致则阻断发布
- 召回阈值默认 ≥0.75，低于阈值不进入 AI 判断

### 4.3 合同审核（ERP 闭环）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| F10 合同上传 | DOCX/PDF，严格模式（甲方/企业法务） | P0 |
| F11 AI 审核 | 解析结构、定位条款、匹配规则、生成意见 | P0 |
| F12 风险工作台 | 高/中风险筛选、待处理/已处理、原文定位 | P0 |
| F13 法务决策 | 采纳/修改后采纳/不采纳 AI 建议 | P0 |
| F14 审核报告 | 导出含结论、风险概况、重点清单的 PDF/Word | P0 |

## 5. 核心流程

### 5.1 规则库建设流程

1. 上传精简审核原则 Word  
2. AI 识别 17 项结构化原则  
3. 生成 26 条候选规则 → 法务逐条确认  
4. 创建测试入库任务 → FastGPT 切片/向量化/索引  
5. RAG 检索测试通过 → 发布规则库 V1.0  

### 5.2 合同审核流程

1. 上传乙方合同  
2. AI 解析 + RAG 召回规则  
3. 生成风险清单（高 25 / 中 13，示例合同）  
4. 法务处理每条风险并定位原文  
5. 生成审核报告供谈判使用

## 6. 数据模型（核心实体）

| 实体 | 关键字段 |
|------|----------|
| 审核原则 | 主题、描述、置信度、来源文件 |
| 候选规则 | rule_id、风险等级、触发表达、建议口径、状态 |
| 入库任务 | job_id、dataset_id、规则数、FastGPT 任务 ID、状态 |
| 规则切片 | chunk_id、来源规则、文本、向量 ID |
| 审核风险 | 条款号、等级、问题描述、后果、建议、决策状态 |

## 7. 验收标准

| 编号 | 验收项 |
|------|--------|
| AC-01 | 上传原则后 2 分钟内完成识别并展示 17 项原则 |
| AC-02 | 26 条候选规则均可编辑、采纳、不采纳 |
| AC-03 | FastGPT 回调后切片/向量/索引数量一致 |
| AC-04 | 价格类测试条款召回 ERP-PRICE-001/002，相似度 >85% |
| AC-05 | 合同审核识别 ≥35 条风险，每条可定位原文页码 |
| AC-06 | 审核报告同步当前法务处理状态 |

## 8. 风险与依赖

| 风险 | 缓解措施 |
|------|----------|
| 大模型幻觉生成规则 | 法务必审 + 置信度阈值 + Bad Case 复盘 |
| RAG 召回错误导致漏审 | 混合检索 + 阈值过滤 + 多规则交叉验证 |
| 敏感合同数据外泄 | 私有部署、数据不出域、审计日志 |

**外部依赖**：FastGPT 知识库 API、企业中文 Embedding 模型、大模型推理服务。
